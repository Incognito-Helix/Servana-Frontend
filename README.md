# Servana Frontend

Frontend for Servana platform.

## Tech Stack

- React + Vite
- Javascript
- Tailwind CSS

## How to run

1. Install dependencies:
   npm install

2. Copy env file:
   copy .env.example .env

On Mac/Linux:
cp .env.example .env

3. Update .env with your keys (API URL, Paystack key, Google client ID)

4. Start dev server:
   npm run dev

5. Open http://localhost:5173 in browser

## Scripts

- npm run dev - start dev server
- npm run build - build for production
- npm run preview - preview build
